# Frontend Integration Guide

## Overview

The web UI has been fully integrated with the Rust backend. This document describes the setup and deployment process.

## Project Structure

```
server/
├── webui/                    # Web UI frontend
│   ├── src/                  # TypeScript source
│   ├── dist/                 # Built frontend (generated by build)
│   ├── index.html            # Entry point
│   ├── package.json          # Dependencies
│   ├── vite.config.ts        # Vite configuration
│   ├── tsconfig.json         # TypeScript config
│   ├── uno.config.ts         # UnoCSS config
│   └── README.md             # Frontend documentation
└── src/
    └── main.rs               # Rust server (updated to serve webui)
```

## Development Workflow

### Full Stack Development

1. **Build the Frontend**

   ```bash
   cd server/webui
   pnpm install
   pnpm build
   ```

2. **Run the Rust Server**

   ```bash
   cd server
   cargo run
   ```

3. **Access the UI**

   Open browser to: `http://localhost:8080/webui/`

   The server will redirect `/` to `/webui/` automatically.

### Frontend-Only Development (with Mock API)

For faster iteration on the frontend without the Rust backend:

```bash
# Terminal 1: Start mock API
cd server/webui
node build/mock-api-server.mjs

# Terminal 2: Start Vite dev server
cd server/webui
pnpm dev
```

Then open: `http://localhost:3000/`

**Test Credentials:**
- Username: `admin`
- Password: `password123`

### Live Reload Development (with Rust Backend)

For development with live reload:

```bash
# Terminal 1: Start Rust server (will auto-reload on changes)
cd server
cargo watch -x run

# Terminal 2: Start Vite dev server
cd server/webui
pnpm dev
```

The Vite dev server proxies API requests to the Rust server via the configuration in `vite.config.ts`.

## Building for Production

```bash
# Build the frontend
cd server/webui
pnpm build

# The dist/ folder is served by the Rust server at /webui/
# Start the Rust server normally
cd ../
cargo build --release
./target/release/obsidian-publisher-server
```

Access the UI at: `http://localhost:8080/webui/`

## File Structure Details

### Frontend Entry Point

The frontend is served from `server/webui/dist/` after building:

- `index.html` - Main HTML file
- `app.js` - Bundled JavaScript (with all source code)
- `uno.global.css` - Generated UnoCSS styles (if configured)
- `assets/` - Static assets

### Rust Server Integration

The Rust server (`server/src/main.rs`) has been updated to:

1. **Serve the webui at `/webui/`**
   ```rust
   .nest_service(
       "/webui",
       ServeDir::new("webui/dist")
           .fallback(get(|| async { Redirect::permanent("/webui/") }))
   )
   ```

2. **Redirect root to `/webui/`**
   ```rust
   .route("/", get(|| async { Redirect::permanent("/webui/") }))
   ```

3. **CORS is enabled** for API requests

## API Endpoints

All API endpoints are accessible from the frontend:

### Auth Endpoints
- `POST /auth/register` - Register new user
- `POST /auth/login` - Login user
- `GET /auth/me` - Get current user (requires token)

### User Endpoints
- `GET /user/profile` - Get user profile (requires token)
- `PUT /user/profile` - Update user profile (requires token)
- `GET /user/stats` - Get user statistics (requires token)
- `DELETE /user/account` - Delete user account (requires token)

### Sites Endpoints
- `GET /api/sites` - List all public sites
- `POST /api/sites` - Upload new site (requires token)
- `PUT /api/sites/{id}` - Update site info (requires token)
- `DELETE /api/sites/{id}` - Delete site (requires token)

### Admin Endpoints
- `GET /api/admin/all` - Debug endpoint
- `GET /api/admin/sites` - Check DB/disk mismatch
- `GET /api/admin/storage` - Get storage usage

## Deployment

### Docker Setup

The Docker configuration should be updated to build the frontend:

```dockerfile
# Build frontend
FROM node:18 AS webui-builder
WORKDIR /app/server/webui
COPY server/webui/package.json server/webui/pnpm-lock.yaml ./
RUN npm install -g pnpm && pnpm install
COPY server/webui/src ./src
COPY server/webui/*.html ./
COPY server/webui/*.ts ./
RUN pnpm build

# Build server
FROM rust:1.75 AS server-builder
WORKDIR /app
COPY . .
COPY --from=webui-builder /app/server/webui/dist ./server/webui/dist
RUN cargo build --release

# Runtime
FROM debian:bookworm-slim
COPY --from=server-builder /app/target/release/obsidian-publisher-server /usr/local/bin/
EXPOSE 8080
CMD ["obsidian-publisher-server"]
```

### Environment Variables

For the frontend (if using environment-based configuration):

```env
VITE_API_URL=http://localhost:8080
VITE_AUTH_URL=http://localhost:8080/auth
```

These are optional as the frontend detects the API URL from `window.location.origin`.

## Troubleshooting

### Frontend not loading

1. **Check if frontend was built**
   ```bash
   ls server/webui/dist/
   # Should contain: index.html, app.js, uno.global.css
   ```

2. **Check Rust server logs**
   ```
   info!("🚀 Server running on...")
   ```

3. **Try accessing the API directly**
   ```bash
   curl http://localhost:8080/auth/login
   # Should return 405 (Method Not Allowed) or similar API response
   ```

### API requests failing

1. **Check CORS headers** - Frontend at `http://localhost:8080/webui/` making requests to `/auth/` should work
2. **Check authentication** - Some endpoints require Bearer token in Authorization header
3. **Check backend is running** - Ensure Rust server is started with `cargo run`

### Development server not proxying requests

The Vite dev server at `localhost:3000` proxies requests to `localhost:8080`:

1. **Ensure Rust server is running** on port 8080
2. **Check vite.config.ts** proxy configuration
3. **Check browser console** for network errors
